Phase 1 — Auth + Core Entry + Task Module

04Authentication เชิงลึก Phase 1

ทำไม SHA-256 ไม่พอกับรหัสผ่าน · JWT ไม่ได้เข้ารหัส (และแปลว่าอะไร) · refresh rotation จับการขโมย token ได้อย่างไร · และ IDOR ที่ป้องกันสามชั้น

Argon2id · salt · timing attack · JWT · cookie flags · CSRF/XSS · CORS · rate limit

05Plugin Architecture และ DI Phase 1 · จุดขาย

หัวใจของโปรเจกต์: เพิ่มโมดูลใหม่โดยแก้โค้ดเดิม 0 บรรทัด ทำได้อย่างไร และ decorator กับ metadata ทำงานเบื้องหลังอย่างไร

SOLID · coupling · DI container · decorator · reflect-metadata · registry · event bus

06ออกแบบ API และตรวจข้อมูล Phase 1

401 กับ 403 ต่างกันตรงไหน · ทำไม offset pagination พังเมื่อข้อมูลเปลี่ยน · และการกันเขียนทับงานคนอื่นด้วย version เดียว

REST · status code · RFC 9457 · cursor pagination · Zod · optimistic concurrency · tracing

07Frontend และการจัดการข้อมูล Phase 1

แยก server state ออกจาก client state · optimistic update ครบ 6 ขั้นที่ต้องมี · และห้าสถานะที่ทุกลิสต์ต้องมี (สามตัวท้ายคือที่คนมักลืม)

React · RSC · App Router · TanStack Query · Zustand · Tailwind token · a11y

10Design System, CSS และ Theming Phase 2a

cascade และ layer ทำงานอย่างไร · แยกความหมายของสีออกจากค่า · dark mode ที่ไม่กระพริบ · คำนวณ contrast เอง · ฟอนต์ไทยกับ letter-spacing

cascade · specificity · @layer · custom property · design token · Tailwind v4 · next-themes · WCAG contrast · next/font

11Component ที่ทุกคนใช้ได้ และ App Shell Phase 2a

accessibility tree คืออะไร · ARIA ที่ต้องชดเชยเมื่อไม่ใช้ element จริง · roving tabindex · คืนโฟกัสหลังปิดเมนู · layout ที่เปลี่ยนตามจอโดยไม่ใช้ JS

12หน้า Tasks: URL state และ Regex parser Phase 2a

state ควรอยู่ที่ไหน · push vs replace · regex ที่รองรับสระไทย · ออกแบบ query key ให้สดพร้อมกันทุกจุด · นาฬิกาที่เดินโดยไม่ยิง API

13Task API: Sidebar, Focus Timer, Race Condition Phase 2a

instant vs หน้าปัด vs โซนเวลา · DST · นับด้วย GROUP BY · check-then-act พังอย่างไร · ให้ฐานข้อมูลตัดสินด้วย partial unique index

14ไอคอน PWA, Visual Regression และ axe Phase 2a

manifest · maskable · visual regression · page.route · page.clock · axe-core · alpha compositing

15เงิน, เดือนตามโซนเวลา และโมดูลที่สอง Phase 2b

ทำไมเงินต้องเก็บเป็นสตางค์ · "เดือนนี้" ของคนไทยเริ่ม 17:00 UTC · เพิ่มโมดูลทั้งโมดูลโดยแก้โค้ดเดิม 2 บรรทัด · แปลง "กาแฟ 65" ด้วย regex

IEEE 754 · minor unit · Intl.NumberFormat · month bounds · plugin architecture · named group · longest match · table-driven test

16การเกิดซ้ำ: floating time และวันสิ้นเดือน Phase 3

อ่าน RRULE · ทำไม "ทุกวัน 9 โมง" ไม่ใช่ทุก 24 ชม. · บิลวันที่ 31 ในเดือนกุมภาฯ · สร้างล่วงหน้า 90 วันโดย cron รันซ้ำก็ไม่สร้างซ้ำ

RFC 5545 · BYSETPOS · floating time · DST · lazy materialization · skipDuplicates · Vercel Cron · fail closed

17การเตือนที่ไม่หาย ไม่ซ้ำ ตรงเวลา Phase 4

ทำไมไม่ใส่ job 6 เดือนลง Redis · sweeper ที่รันซ้ำได้ · กด "จ่ายแล้ว" จาก notification · สรุปรายวัน 07:00 ของใครของมัน · alert ที่มี unit test

18พิมพ์ประโยคเดียวแล้วได้ของจริง Phase 5
