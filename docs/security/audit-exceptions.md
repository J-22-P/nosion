# ข้อยกเว้นของ `pnpm audit`

CI รัน `pnpm audit --audit-level=high` (📁 `.github/workflows/ci.yml`) — ช่องโหว่ระดับ high/critical ทำให้ job "Security scan" แดง
ข้อยกเว้นอยู่ใน `package.json` → `pnpm.auditConfig.ignoreGhsas` ซึ่ง **ใส่คอมเมนต์ไม่ได้** เหตุผลจึงต้องอยู่ที่ไฟล์นี้

## กติกา

1. แก้ก่อนเสมอ: อัปเดต dependency ตรง → `pnpm.overrides` (ถ้าอยู่ใน semver range เดิม) → อัปเกรดตัวแม่
2. ยกเว้นได้เมื่อ **ไม่มีเวอร์ชันที่แก้แล้ว** หรือแก้แล้วพังสิ่งที่ใหญ่กว่า — และต้องเป็น devDependency ที่ไม่รับ input จากผู้ใช้
3. ทุกข้อยกเว้นมีวันทบทวน · ถึงวันแล้วรัน `pnpm audit` ใหม่ — ถ้ามีเวอร์ชันที่แก้แล้ว ลบข้อยกเว้นทิ้ง
