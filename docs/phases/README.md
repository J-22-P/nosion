# บันทึกการทำงานราย Phase

เอกสารชุดนี้ตอบคำถาม **"ทำอะไรไปแล้ว ทีละขั้น และตรวจอย่างไร"**
ต่างจากเอกสารชุดอื่นในโฟลเดอร์ `docs/`:

| โฟลเดอร์       | ตอบคำถาม                              | อ่านเมื่อ                         |
| -------------- | ------------------------------------- | --------------------------------- |
| `docs/phases/` | ทำอะไรไป ขั้นไหน commit ไหน เหลืออะไร | กลับมาทำงานต่อ / รีวิวความคืบหน้า |
| `docs/learn/`  | ความรู้เบื้องหลังโค้ด                 | อยากเข้าใจ / เตรียมสัมภาษณ์       |
| `docs/adr/`    | ทำไมถึงตัดสินใจแบบนี้                 | สงสัยว่าทำไมไม่ทำอีกแบบ           |

## กติกา

1. ทุก Phase มีไฟล์ของตัวเอง ทุก **ขั้น** (1 ขั้น ≈ 1 commit) มีหัวข้อย่อยของตัวเอง
2. แต่ละขั้นบันทึก 5 อย่าง: **เป้าหมาย · สิ่งที่เปลี่ยน · การตัดสินใจ · วิธีตรวจ · สิ่งที่ค้าง**
3. อัปเดตไฟล์นี้ใน commit เดียวกับงาน (หรือ commit ถัดไปทันที) — ไม่เขียนย้อนหลังเป็นก้อนใหญ่
4. อะไรที่ "ยังไม่ได้ตรวจ" ต้องเขียนตรง ๆ ว่ายังไม่ได้ตรวจ
5. ทุกขั้นมีบรรทัด 📚 ชี้ไปหัวข้อใน `docs/learn/` ที่อธิบาย **ความรู้พื้นฐาน** ของขั้นนั้น
6. ทุก Phase มีบทใน `docs/learn/` ของตัวเอง เขียนระดับเดียวกับบท 02–07:
   ปัญหาที่แก้ → พื้นฐานตั้งแต่ศูนย์ → พาเดินโค้ดจริงทีละขั้น (📁) → กับดัก (⚠️) → คำถามสัมภาษณ์ (🎤)
   → ข้อเสียที่ยอมรับ → แบบฝึกหัดท้ายบท
